# 碎记 · 一个简单的2025总结

好困啊😪

本想着还有时间慢慢来不急，一转眼就31号了呢……

那就敷衍地写一下吧，也算对自己有个交代。

----

2025算是变化相当大的一年。

高考、综合评价、上大学、现在又到了期末周。

获得了新的电脑、手机和平板。

代码主要在11月12月集中在爆肝。

水群感觉比以前多很多（

然后加入了sysu的M记和MSC，感谢师兄看得上我这种fw🙏里面的氛围终于让我有动力重新开始肝代码了（

----

高考结束之后也算是打开了一个心结吧，在那之后基本是报仇雪恨般地摸鱼（写代码也算在内）。

去了旅游去了AOSCC和子兰meetup，很开心，希望还能有（

----

实体书今年没怎么读了，果然我还是会倾向于电子书啊。不过可能以后还是划定个时间来看书会比较好

----

一如既往的不想上课。

在大学尝试逃课并且获得了成功，在那之后我就基本上只去会点名的课了，当然其实偶尔还是会去一下的。

嘛，也理所应当的学不明白，但是自己开心了就足够了。

----

自然，也是一如既往的不想复习。

高考前一天晚上我还搁那用备考室的课室的电脑看unsloth文档呢。到了大学也没有改变，老师在上面复习我在下面写代码聊天啥的。总之我这个人是比较讨厌复习的，但是其实自己也学不明白，唉不上不下了。

时间规划能力其实也是一如既往的差，在大学已经下了5次决心要00:00前睡觉了，但是除了生病的日子之外没有一天是做到的。

任务规划能力一样，压根分不清哪个高优先级哪个低，反正自己记起来什么就做什么，喜欢做什么就做什么。所以一直都是游走在DDL边沿然后疯狂垂死挣扎。也吃了挺多苦头的吧就是。

----

今年下半年主要是在赶任务和填自己以前挖的坑。

再来一次感谢M记和MSC，终于给了我重新开始写代码的动力

目前直到年底在做的项目有：

- class-calender-generator
- bbg-next
- 一个内核构建的actions仓库
- LiteQuantize

另外感觉换了Macbook Pro之后有了工作动力+300%的效果，这玩意不会含有SCP-1011吧（x）以前用Legion的时候一天到晚只想聊天和玩游戏（

----

嗯来记录一下设备的变动吧。

首先是从AOSCC 2025回来之后因为无法忍受iPhone 8的卡顿，润到了OnePlus 13。

然后因为要上大学在muji的推荐下购入了Samsung Galaxy Tab S9 Wi-Fi。

上大学之后Legion在期中后的某个周六因为风扇异常+主板电容故障直接烧了，后面换了mbp，感谢gztime师兄和另一位师兄（

最后是复活了Xiaomi Mi Max 2，不过因为我的主力机变成了OP 13所以它已经不常用了，只是偶尔玩玩。

唉写了设备变动才发现欠了好多文章呢。想写我这个三星板子怎么在不解锁BL的情况下切换到国外固件（谢谢db的指导）、更新那篇OP 13 PJZ110切换到OOS的教程、写OP 13切换到LOS 23并且做优化的教程（好吧其实自己也还在探索着）、写入门向的KSU内核编译的教程……

----

最近混安卓圈子了，先膜拜一下Ray和db两位佬佬！

Root方案从 Magisk -> APatch -> YAPatch -> SukiSU Ultra -> Magisk Alpha -> KowSU -> ReSukiSU （只是从探索的时间来划分，不都是在同一台机子搞的）。暂时是稳定在主力机和三星板子用的KowSU LKM，Mi Max 2用的自己编译的ReSukiSU NonGKI内核了。

也算是用Frozen + ReKernel + Thanox情景模式（酷安上的多开后台管家）实现了极限的省电（目前好像是OP 13极限可以用1天6小时）。

还想玩很多东西，还想继续在安卓圈子折腾……菜菜捞捞呜呜

----

高强度vibe coding中……

今年没有太关注量化，而是去体验了很多vibe coding和AI Agent，尝试把自己的学习和生活更深程度地接入AI。说到这就不得不感慨还是安卓好啊，苹果的话我几乎就没有尝试的空间了。

嗯不过LiteQuantize这个WebUI在写了，敬请期待吧。

在最后骂一下GLM 4.7和MiniMax 2.1，端出来的什么玩意也敢吹。

----

哦对有个大乌龙。

今年英语四级忘记参加了😇这么重要的考试能睡过头（睡到9:01醒）我也是神人了，我要不把我id改成5个字算了（）

也罢和还没考的朋友一起考吧，可能感觉也不错（

----

好吧其实写到这里已经不太想写了（）

那就祝看到这篇文章的各位，2026新年快乐，心想事成啦。
